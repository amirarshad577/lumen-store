# Lumen & Co. — React E-commerce Storefront

Stack: React 18, Vite, Tailwind CSS, React Router DOM v6, Lucide React, Context API + LocalStorage cart.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

Edit products in `src/data/products.js`. Checkout is a demo (no payment gateway).
